# Ivan Cabrilo website

Published at https://ivancabrilo.github.io/ using GitHub Pages from the main branch.

The personal Home page is the landing page (`index.html`); the game is `game.html`. The previous `personal.html` address redirects to Home.

Initial site copied from `ivancabrilo/personal_website` revision `99070aa72f8a17669c81cfec38bd31a6d0f2d137`. The original project remains available separately. Changes to the main website should be made in this repository.

Run `npm test` to check game behavior. Run `npm run prepare-deploy` after asset edits to update cache versions.
